ארכיטקטורה בפועל

דפדפן Vite/React←→Supabase Auth + PostgREST/RLS←→Express API←→ספקים חיצוניים

הדפדפן משתמש גם ב־Supabase ישירות וגם ב־Express. נתוני מודולים רבים נקראים/נשמרים דרך שכבות localStorage ו־sync. זה עובד, אך מגדיל מספר מסלולי אמת ומחייב מטריצת סנכרון ובדיקות קונפליקט.

מה כבר טוב

  • עבר כל route API הרגיש שנבדק משתמש ב־requireUser; CRM/impersonation משתמשים גם ב־requireAdvisor.
  • עבר Express כולל Helmet, rate limit גלובלי, מגבלת JSON של 2MB, CORS allowlist ו־error response שאינו חושף stack.
  • עבר קיים RPC קנוני upsert_client_state עם SECURITY INVOKER, revoke ל־public/anon ו־grant ל־authenticated.
  • עבר קיימים RLS migrations, audit_logs, triggers, security baseline script ו־E2E tenant isolation.
  • עבר frontend אינו מכיל service-role reference לפי סריקת security baseline.
